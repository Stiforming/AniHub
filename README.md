## English version of the read me

# AniHub

AniHub is an application made for English and French-speaking users who are a little too lazy to search for the URLs of anime streaming websites such as Anime-Sama, HiAnime, etc.

With AniHub, you can simply open the application and you'll be redirected to the current official Anime-Sama website. How do you know which one is official? I either visit anime-sama.pw or check the Anime-Sama Discord server to find the official website.

If you click on the English language option, you'll be redirected to HiAnime, which is an unofficial one but seems to be safe for usage.

AniHub includes a custom ad blocker. It deletes all ads possible from websites, and also blocks redirections, either coming from hidden ads or a ad that went through the adblock. This means you don't need to install an additional ad blocker, as one is already built into the application.
