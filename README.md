# AniHub
AniHub est une application faite pour les utilisateurs anglais/français qui ont un peu la flemme de chercher les urls des sites anime streaming comme anime-sama, hianime etc.

Avec Anihub, vous pouvez juste ouvrir l'application et vous serez dirigé vers le site d'anime-sama actuel (l'officiel) comment savoir si c'est l'officiel? je visite anime-sama.pw ou bien je vais dans le serveur discord d'anime sama pour le chercher. Si vous cliquez sur le langage anglais (english) vous allez tomber sur hianime, qui semble aussi être l'officiel. 

AniHub contient un bloqueur de publicité partiel. Il autorise l'affichage de la pub, mais les pub caché (ce que vous ne voyez pas, mais aussi les pubs que vous voyez de toute façon) sont bloqué. Donc vous n'avez pas besoin d'installer un bloqueur de pub car il y en a un directement intégré a l'application.

Si vous connaissez des sites qui ont des autre langages, contacter moi sur discord, mon username est tempmistaelon (Si vous essayer de me dire d'ajouter un site web douteux, je refuserai et je vous bloque sur le champ.)

## English version of the read me

# AniHub

AniHub is an application made for English and French-speaking users who are a little too lazy to search for the URLs of anime streaming websites such as Anime-Sama, HiAnime, etc.

With AniHub, you can simply open the application and you'll be redirected to the current official Anime-Sama website. How do you know which one is official? I either visit anime-sama.pw or check the Anime-Sama Discord server to find the official website.

If you click on the English language option, you'll be redirected to HiAnime, which also appears to be the official website.

AniHub includes a partial ad blocker. It allows advertisements to be displayed, but blocks hidden ads (ads you don't actually see) as well as ads that are displayed but are not meant to be interacted with. This means you don't need to install an additional ad blocker, as one is already built into the application.
